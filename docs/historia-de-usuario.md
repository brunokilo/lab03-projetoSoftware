HU01 — Gerenciar login
Como usuário, quero realizar o login no sistema para poder acessar as funcionalidades disponíveis para o meu perfil.

HU02 — Selecionar instituição
Como aluno, quero selecionar uma instituição de ensino para poder utilizar os benefícios relacionados a ela.

HU03 — Selecionar vantagem
Como aluno, quero selecionar uma vantagem disponível para poder utilizar minhas moedas.

HU04 — Enviar moedas
Como professor, quero enviar moedas estudantis para um aluno para recompensar umm aluno.

HU05 — Notificar aluno
Como aluno, quero receber notificações quando eu receber moedas estudantis.

HU06 — Trocar moedas
Como aluno, quero trocar minhas moedas estudantis por vantagens para poder usufruir dos benefícios disponíveis.

HU07 — Consultar extrato da conta
Como usuário, quero consultar o extrato da minha conta para poder acompanhar minhas movimentações de moedas estudantis.

HU08 — Informar lista de professores
Como instituição, quero informar a lista de professores para poder disponibilizá-los no sistema.

HU09 — Cadastrar conta
Como empresa, quero cadastrar uma conta para poder disponibilizar as vantagens que posso oferecer em troca de moedas.

HU10 — Cadastrar vantagens
Como empresa, quero cadastrar vantagens e registrar descrição e foto das vantagens.
